## TCGA-BRCA cohort definition (canonical, 631 samples)

The cohort is fixed deterministically: **all 113 "Solid Tissue Normal"
files + a random draw of 520 "Primary Tumor" files
(`random.Random(42).shuffle` over the manifest order), keeping the FIRST
file per barcode** (two drawn barcodes have two GDC file entries from a
reprocessed workflow; the first in draw order is canonical and was
byte-verified). The draw yields 518 unique tumor barcodes → 518 tumors +
113 normals = 631 samples, matching the manuscript. `01_download_data.py`
reproduces this selection; the manifest snapshot shipped in `data/` pins
the GDC file identifiers.

## Re-audit note (2026-09-20)

- The `randDE` control in `03_nested_compression.py` was corrupted by a
  namespace bug (Ensembl IDs compared against a gene-symbol set, so the
  nearest-gene filter never excluded panel genes and `randDE` silently
  equaled Panel B, 95.8%). Fixed (symbol-based matching, now centralized
  in `pipeline_utils.pick_nearest_non_panel` with a regression test,
  `test_namespace_guard.py`); the corrected control reproduces the
  manuscript value (98.1%, > 499/500 null draws).
- Null statistics are quoted from the deterministic re-run: median 92.7%,
  IQR 90.1–94.9%, range 80.6–98.4%, median AUC 0.957 (B = 500).
- The METABRIC transfer estimate was re-taken with a full cBioPortal
  response: 99.3% of 1,980 tumors called tumor (an earlier 92.4% resulted
  from a partial API response during throttling; PAM50 capture rates and
  all clinical association values reproduced unchanged).
- ESTIMATE baseline and PC1 values quoted in the manuscript are from the
  current canonical re-run (stromal 81.8%; PC1 separation 1.56 → 0.38 SD;
  explained variance 12.4% → 11.8%).
- Second-model analyses (Sections 2.4–2.5) previously relied on a
  non-public readout model (DA-RPE). They were replaced by a fully public
  equivalent: the adipose-axis score rule (A score of the 15-gene panel,
  threshold calibrated on TCGA out-of-fold scores; script
  `09_clinical_models.py`). The private model will not be released; no
  manuscript number depends on it anymore.
- Follow-up audit fixes (2026-09-20): ESTIMATE gene-set membership was
  misaligned to the expression matrix (scores now computed over the
  correct genes; stromal 81.9%, combo 98.1%); `07_transfer.py` now uses
  the same per-sample z-score space on both sides of the transfer
  (GTEx 99.6%, METABRIC 93.5%); null AUC quantiles accumulate over all
  15 splits; xarray pinned (required by rdata for R arrays).
- Adversarial re-audit of Section 2.3 (2026-09-22): the global ablation
  (98.9 -> 90.9) establishes route DEPENDENCE, not adipose identity. A
  paired-score contrast (script `10_score_contrast.py`; B = 30
  randomized |Delta|-matched non-adipose control scores) removes more
  accuracy than the adipose score itself (84.7% vs 90.9%; excess = -0.35,
  paired t = +4.25). The manuscript's Section 2.3 was reframed
  accordingly (dependence vs. specificity; specificity anchored on the
  Sections 2.4-2.6 triangulation). An earlier version of the contrast had
  a degenerate control (deterministic pairing made all B = 30 replicas
  identical); fixed with randomized neighbour selection.
- The "high centroid-separation confidence stratum" of the earlier
  manuscript version was removed: in the private script the margin was
  computed as (second-best − best) centroid correlation, so
  `margin >= P75` actually selected the LOWEST-confidence quartile
  (mislabelled). The published section now uses the full-sample PAM50
  analysis (chi-square with and without the normal-like class), which is
  fully public and stronger.
